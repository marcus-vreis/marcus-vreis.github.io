Train, validate and compare models on your own GPU — no cloud, no notebooks, no
copy-pasted training loops. Five task families behind one interface
(`classification`, `detection` with YOLO and RT-DETR, `regression`,
`segmentation` and `anomaly`), `timm` backbones, Optuna-guided sweeps and an
SDK for custom tasks. Published on PyPI as `visionforge-studio`, with
hardware-aware setup via `visionforge doctor --fix` (which inspects the NVIDIA
driver and installs the matching PyTorch wheel, from Turing `sm_75` through
Blackwell `sm_120` on `cu128`).

What the project argues is easy to say and rare to find: **the number you report
has to be a number you can defend**. Every configuration is validated by
Pydantic v2 before touching GPU time (ADR-002), every run writes a full
provenance contract to `run.json` (ADR-013, including environment and schema
version), and every comparison can be replicated across multiple seeds with
bootstrap confidence intervals. Over 120 ADRs document every architectural
decision in the repository.
