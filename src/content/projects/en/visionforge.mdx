[VisionForge](https://github.com/marcus-vreis/VisionForge) unifies five computer-vision task families behind a single interface and Python SDK (`classification`, `detection` with YOLO and RT-DETR, `regression`, `segmentation`, and `anomaly`), pairing `timm` backbones with Optuna hyperparameter sweeps. The package is published on PyPI as [`visionforge-studio`](https://pypi.org/project/visionforge-studio/) and archived on Zenodo under DOI [`10.5281/zenodo.23425765`](https://doi.org/10.5281/zenodo.23425765). Running `visionforge doctor --fix` inspects the host NVIDIA driver and installs the matching PyTorch wheel across GPU generations (from Turing `sm_75` to Blackwell `sm_120` on `cu128`).

Every training configuration is validated through Pydantic v2 before allocating GPU memory (ADR-002). Completed runs write full execution provenance, environment versions, and random seeds to `run.json` (ADR-013). Model comparisons execute as multi-seed replicates and report bootstrap confidence intervals rather than single-seed point estimates. Over 120 Architecture Decision Records (ADRs) document the design history of the repository.
