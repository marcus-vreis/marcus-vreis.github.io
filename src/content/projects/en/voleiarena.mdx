A white-label SaaS for running footvolley tournaments: brackets, live scoring
and per-client theming. React and Vite on the front end, Supabase behind it.

It ships with five ready-made themes — ocean-deep, sunset-pastel,
forest-green, pastel-sky, volcanic — built on CSS custom properties chosen to
hold WCAG contrast.
