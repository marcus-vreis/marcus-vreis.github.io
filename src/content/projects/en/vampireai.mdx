An agent that plays *Vampire Crawlers* (a turn-based deckbuilder roguelike
released in April 2026 — zero contamination in any model's training data) using
100% local inference through Ollama (`Qwen2.5-VL` 7B). The research question
inverts the usual one: not *"how well can a paid frontier model play"*, but
*"what is the exact boundary between classical computer vision and a
vision-language model so that a small open-weight model plays in real time on a
single GPU"*.

The project's structural rule (ADR-022) is strict: **classical CV decides
geometry; the VLM decides only semantics**. Before anything reaches the model,
every pixel-measurable question is answered by pure functions over NumPy arrays
(`src/vision/`): screen-state classification via colour signatures, card-slot
and cursor detection in **3.3 ms** (tracking the blue-to-magenta pulse of the
cost orb), HUD mana and HP extraction in **1.6 ms** via a runtime-learned
`glyph → digit` codebook (`digits.py`, which queries the model only on the
first two appearances of each digit), and BFS pathfinding on the minimap with
template-matched icons merged into the walkable mask.

That split cut a combat turn's budget from `6 + N` VLM calls down to **1–2
calls per turn** (< 15 s target latency), with Pydantic-validated decisions and
execution through a virtual DualShock 4 gamepad (`vgamepad` over ViGEm Bus)
paced by visual cursor-motion confirmation rather than fixed sleeps (ADR-041).
