[VampireAI](https://github.com/marcus-vreis/VampireAI) plays *Vampire Crawlers* (a turn-based deckbuilding roguelike released in April 2026, outside the pretraining cutoff of current models) using local inference through Ollama (`Qwen2.5-VL` 7B). The project studies where to place the boundary between deterministic image processing and a compact vision-language model to keep turn latency practical during live gameplay.

The architecture follows ADR-022. Pure NumPy and OpenCV functions (`src/vision/`) resolve screen geometry before any VLM call occurs. The vision module classifies screen state from colour signatures, locates card slots and selection cursors in 3.3 ms (handling the blue-to-magenta mana orb pulse), and reads mana and HP in 1.6 ms via a runtime-learned glyph codebook (`digits.py`, which queries the model only on the first two appearances of each digit). Dungeon traversal runs breadth-first search (BFS) directly on the walkability grid extracted from the minimap.

The VLM receives only novel card crops and the structured combat state. Separating geometry from semantics reduced combat cost from `6 + N` model queries to 1–2 calls per turn, with outputs validated in Pydantic and executed through a virtual DualShock 4 controller (`vgamepad` over ViGEm Bus) synchronized by visual cursor confirmation (ADR-041).
