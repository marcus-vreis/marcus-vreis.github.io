An agent that plays Vampire Crawlers, a turn-based deckbuilder roguelike,
using a local vision-language model: Qwen2.5-VL at 7B parameters, served
through Ollama. No paid API, no data leaving the machine.

The research question runs opposite to the usual one. Not "how well can a
frontier model play" but "what is the smallest open-weight model that plays a
turn-based game reasonably". The game shipped in April 2026, so there is zero
contamination in any model's training data.

The pipeline: screen capture, game-state detector, VLM perception, strategy
decision validated by pydantic, virtual gamepad input. A pivot on May 2, 2026
replaced mouse coordinates with a virtual gamepad — cards are now selected
through visual highlight and traversal, which removed all UI calibration.
